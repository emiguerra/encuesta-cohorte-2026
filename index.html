Tipo de gráfico

Cambia cómo se ve el gráfico del slide activo (el resaltado en «Navegar» al hacer scroll). Se actualiza al instante — prueba varias formas para el mismo dato antes de decidir.

Insertar gráficos

Se agregan al slide activo (el resaltado en «Navegar»). Después se editan como cualquier texto.

Cómo editar

Formato fijo 1920×1080, grilla de 8 columnas — cada slide es una pieza de una sola idea. Con «Editar contenido» activo: clic en cualquier texto para escribir encima. Clic en un porcentaje de barra para cambiarlo. Pasa el mouse sobre una fila para ver «Eliminar» / «+ Agregar fila».

Exportar y guardar

Exportar PDF / PPTX descarga el deck completo listo para presentar o compartir. Cada slide se captura como imagen, así que se ve idéntico al editor, pero el texto ya no es editable dentro de esos archivos — para seguir editando, usa «Guardar progreso».

Guardar / Cargar progreso descarga o restaura un .json con tu edición completa, para retomarla otro día o el próximo año.
